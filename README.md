# University Attendance System

A Flutter-based mobile application for managing university attendance, with separate portals for administrators and teachers.

## 🚧 Project Status

This project is currently under active development.

## ✨ Features (Planned)

*   **Admin Portal:** Manage teachers, sections, subjects, and students.
*   **Teacher Portal:** Mark attendance, view student lists, and generate reports.
*   **Authentication:** Secure login for teachers and admins.

## 🛠️ Tech Stack

*   **Framework:** Flutter
*   **Backend:** Firebase (Authentication, Cloud Firestore, Cloud Functions)
*   **State Management:** Provider
